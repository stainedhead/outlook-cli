# Group D notes (doc-impacting and cross-group)

- FR-R8: file ledger implements ReserveWithin (count + reserve under one flock). Entries carry "kind" (send|draft; empty = send for older files). SentSince and rate counts include send-kind entries with status sent OR pending; drafts and failed never count. Plain Reserve = send-kind, no windows.
- FR-R13: ledger.New refuses an existing ledger directory whose mode is not 0700 or not owned by the current uid (exit 1 with hint); re-checked on every locked operation. A missing directory is created 0700. Config.DirInfo/UID are test injection points. Doc impact: a pre-existing shared 0755 state directory (e.g. shared with the audit log) now fails; the ledger needs a private dir. Docs must state caps are guardrails, not defense against a hostile local user.
- FR-R12: use ledger.NewQuarantine(root) (rejects empty root, validation exit). Quarantine{} zero value fails closed in Save. app.go (group B) should switch from the literal `ledger.Quarantine{Root: ...}` to NewQuarantine and surface its error (the literal still compiles and works when Root is non-empty). Containment is checked on the deepest existing ancestor before any mkdir. Name collisions now yield "name (1).ext", "name (2).ext", ... (up to 1000, then conflict) instead of conflict exit.
