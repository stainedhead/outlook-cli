- FR-R10: from/to/cc addresses failing ParseAddress are emitted as an untrusted object with sibling "address_flag":"non_conforming"; link url and domain, folder name are now untrusted objects (output shape change: were plain strings); attachment content_type stays plain only if bare type/subtype, else untrusted.
